## 1. 功能概述

### 1.1 业务背景
归因模板用于指导汽车销量达成异常的四步归因 SOP：
1. **大盘对标** —— 计算品牌整体销量缺口
2. **维度下钻** —— 自动下钻车型与大区，定位最大缺口
3. **跨域归因** —— 关联营销投放、终端客流、竞品折扣
4. **策略建议** —— 生成针对性可执行策略

### 1.2 核心组件

| 组件 | 文件路径 | 职责 |
|-----|---------|------|
| 模板管理器 | `backend/core/attribution_templates.py` | CRUD 模板、系统预设、角色绑定 |
| SOP 引擎 | `backend/core/sop_analyzer.py` | 四步归因分析 |
| 前端选择器 | `frontend/src/components/SopTemplateModal.tsx` | 模板选择 UI |
| 模板市场 | `frontend/src/app/templates/market/page.tsx` | 克隆/浏览模板 |
